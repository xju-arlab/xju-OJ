# 题面参照样板

5 个可直接套用的完整题面。每块都按 OJ 的字段写：描述 / 输入格式 / 输出格式 / 样例（含解释）。
套用时只改题，不要改结构。

---

## 样板 1：数组最值类（单组、两行输入）

### 描述

小天有 $n$ 封信，第 $i$ 封信的微光值为 $a_i$。今夜有 $m$ 束月光，能增加的微光值分别为
$c, c+d, c+2d, \dots, c+(m-1)d$。

小天最多进行一次操作：任选 $m$ 封不同的信，把 $m$ 束月光以任意顺序各使用一次。求操作后
按微光值从大到小排列时，第 $k$ 大的微光值最大能是多少。

### 输入格式

第一行输入五个整数 $n, k, m, c, d$（$1 \le k, m \le n \le 2 \times 10^6$，$0 \le c, d \le 10^9$）。

第二行输入 $n$ 个整数 $a_1, a_2, \dots, a_n$（$0 \le a_i \le 10^9$）。

### 输出格式

输出一个整数，表示第 $k$ 大的微光值最大能是多少。

### 样例 1

输入：

```text
5 3 2 1 3
8 2 5 1 4
```

输出：

```text
6
```

样例解释：

两束月光分别为 $1$ 和 $4$。把 $4$ 加到 $4$ 上、$1$ 加到 $5$ 上，序列变为
$8, 2, 6, 1, 8$，降序为 $8, 8, 6, 2, 1$，第 $3$ 大为 $6$。可以验证不存在让第 $3$ 大
更大的分配。

**为什么这样写**：范围分别贴在两行上，`c, d` 属于第一行，`a_i` 属于第二行；
描述里不出现范围。

## 样板 2：图论类（边表、结构保证）

### 描述

给定一张 $n$ 个点、$m$ 条边的无向连通图，保证图中恰好有一个环（即 $m=n$），没有重边、
没有自环。每个点 $i$ 上写着一个整数 $a_i$，所有 $a_i$ 互不相同。

小红和小紫玩"剥叶子"游戏。每回合，当前玩家选择一个度数为 $1$ 的点 $u$，获得 $a_u$ 分，
然后把 $u$ 从图中删掉。图中不存在度数为 $1$ 的点时游戏结束。两人都采用贪心策略：轮到自己
时选当前可选点中 $a$ 值最大的。问最后谁获胜。

### 输入格式

第一行两个整数 $n, m$（$3 \le n \le 2 \times 10^5$，保证 $m=n$）。

接下来 $m$ 行，每行两个整数 $u, v$（$1 \le u, v \le n$），表示一条连接 $u, v$ 的边；
保证图连通、无重边、无自环，且恰好有一个环。

最后一行 $n$ 个整数 $a_1, \dots, a_n$（$0 \le a_i \le 10^9$），保证 $a_i$ 两两不同。

### 输出格式

输出一行，为 `red`、`purple` 或 `draw`。

### 样例 1

输入：

```text
5 5
1 2
2 3
3 1
1 4
2 5
10 20 30 7 3
```

输出：

```text
red
```

样例解释：

一开始度数为 $1$ 的点只有 $4$（值 $7$）和 $5$（值 $3$）。第 $1$ 回合小红选 $4$ 得 $7$ 分；
第 $2$ 回合小紫只能选 $5$ 得 $3$ 分；之后环上三点度数都是 $2$，游戏结束。$7>3$，输出 `red`。

**为什么这样写**：结构性保证（连通、无重边、恰好一个环）跟在边表之后，不单独开一节；
输出值 `red` 等用行内代码，不进数学环境。

## 样板 3：多测类（$T$ 组 + 总和限制）

### 描述

给定 $T$ 组数据。每组给出一个长度为 $n$ 的整数序列 $a$，求该序列所有元素之和。

### 输入格式

第一行一个正整数 $T$（$1 \le T \le 10^5$），表示数据组数。

接下来 $T$ 组数据，每组：

第一行一个正整数 $n$（$1 \le n \le 10^5$）。
第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$（$-10^9 \le a_i \le 10^9$）。

保证所有数据的 $n$ 之和不超过 $2 \times 10^5$。

### 输出格式

对于每组数据，输出一行一个整数，表示该组序列的和。

### 样例 1

输入：

```text
2
3
1 2 3
2
-1 1
```

输出：

```text
6
0
```

样例解释：

第一组 $1+2+3=6$；第二组 $-1+1=0$。

**为什么这样写**：全局的"$n$ 之和"限制放在输入描述末尾，单独一句，不塞进第一行括号；
$T$ 组结构用"接下来 $T$ 组数据"分组描述，不重复写 $T$ 次。

## 样板 4：构造 + 多组样例

### 描述

给定两个整数 $n, m$，以及长度为 $m$ 的序列 $p_1, \dots, p_m$ 与 $a_1, \dots, a_m$。

你需要构造一个长度为 $n$ 的整数序列 $b_1, \dots, b_n$，满足：

1. $0 \le b_i \le 2^{30}$，且 $b$ 中元素允许重复；
2. 对每个 $1 \le j \le m$，都有 $b_1 \oplus b_2 \oplus \cdots \oplus b_{p_j} = a_j$。

在所有满足条件的序列中，求出字典序最小的那一个并输出。

### 输入格式

第一行两个整数 $n, m$（$1 \le m \le n \le 10^5$）。

第二行 $m$ 个整数 $p_1, \dots, p_m$（$1 \le p_j \le n$），保证 $p_1, \dots, p_m$ 两两不同。

第三行 $m$ 个整数 $a_1, \dots, a_m$（$0 \le a_j < 2^{30}=1073741824$）。

构造出的序列需要满足 $0 \le b_i \le 2^{30}=1073741824$。

题目保证：在给定的数据范围内，一定存在满足条件的序列。

### 输出格式

输出一行 $n$ 个整数 $b_1, \dots, b_n$，表示字典序最小的合法序列。

### 样例 1

输入：

```text
2 1
2
1
```

输出：

```text
0 1
```

样例解释：

要求 $b_1 \oplus b_2 = 1$。取 $b_1=0$ 时 $b_2=1$，已经是字典序最小的方案。

### 样例 2

输入：

```text
5 3
2 4 5
5 5 3
```

输出：

```text
0 5 0 0 6
```

样例解释：

前两个限制给出 $b_1 \oplus b_2 = 5$，前四个给出 $b_1 \oplus b_2 \oplus b_3 \oplus b_4 = 5$，
前五个给出 $b_1 \oplus \cdots \oplus b_5 = 3$。取 $b_1=b_3=b_4=0$、$b_2=5$、$b_5=6$ 最小。

**为什么这样写**：构造题给 2–4 组小样例；"题目保证存在解"放在输入末尾，
用一句保证而不是塞进范围。

## 样板 5：长故事类（题意后置）

### 描述

（背景，可长可短）亚托莉对着课本冥思苦想，夏生坐到旁边陪她做题。窗外天色渐暗，
草稿纸翻过一页又一页……最后，题目是这样的：

给定一个长度为 $n$ 的非负整数序列 $a$，求：

$$\operatorname{mex}(a) \times \min(a)$$

其中 $\operatorname{mex}(a)$ 表示未在序列 $a$ 中出现的最小非负整数，$\min(a)$ 表示
序列 $a$ 中的最小值。

### 输入格式

第一行包含一个正整数 $n$（$1 \le n \le 10^5$）。

第二行包含 $n$ 个非负整数 $a_1, a_2, \dots, a_n$（$0 \le a_i \le 10^9$）。

### 输出格式

输出一个整数，表示答案。

### 样例 1

输入：

```text
2
0 1
```

输出：

```text
0
```

样例解释：

$\operatorname{mex}(0,1)=2$，$\min(0,1)=0$，乘积为 $0$。

**为什么这样写**：故事可以长，但题意必须完整出现在描述里；定义用数学环境，
范围仍逐行贴在输入描述上。
