# 发布前检查清单

题面或数据从"改完"到"发布"之前逐项过。每项都对应一次真实踩坑或团队约定。

## A. 字段归属

- [ ] `description` 里没有数据范围、没有样例解释、没有"第一行……"这类输入格式。
- [ ] `input_description` 逐行描述，范围全部在括号里。
- [ ] `output_description` 写清行数、每行内容、多解/SPJ 判定。
- [ ] 样例解释在 `samples[].explanation`，不在 `hint`。
- [ ] `hint` 为空，或只含非范围、非样例解释的补充说明。
- [ ] `data_range` 为空（本 OJ 不使用独立"数据范围"栏）。

## B. 范围与对应关系

- [ ] 每个范围都贴着它约束的那一行/那个变量，没有堆在输入末尾。
- [ ] 一行多个参数时，范围一次列全：`（$1 \le n \le 10^5$，$0 \le k \le n$）`。
- [ ] 全局约束（$T$ 组总和、$\sum n$）单独一句放在输入末尾。
- [ ] 变量与范围匹配：`c, d` 属于第一行就写第一行，不要挂到 `a_i` 那行。
- [ ] 结构性保证（排列、连通、无重边、恰好一个环、$m=n$）保留原意，没有遗漏。

## C. 公式与符号

- [ ] 所有变量都在 `$...$` 里：`$n$`、`$k$`、`$T$`、`$a_i$`、`$x_p$`、`$f(x)$`。
- [ ] 没有 `a$_1$`、`a1`、`aN`、裸 `n`、`1≤n≤1e6` 这类写法。
- [ ] 连续下标写成 `$a_1, a_2, \dots, a_n$`。
- [ ] 分数用 `\\frac{}{}`（`$\\frac{n}{2}$`），没有 `n/2`、`1/n`。
- [ ] 范围统一 `\\le`、`\\times`、`\\sim`、`10^{18}`，不是 `<=`、`×`、`~`。
- [ ] 数学环境外用中文全角括号/逗号；数学环境内用英文逗号分隔变量。
- [ ] 单位、代码名、英文专名没进数学环境：`TeamA`、`km/s`、`64 位`、`red`。
- [ ] 定义类符号（`$\\operatorname{mex}(a)$`、`$\\min(a)$`）写法一致。

## D. 样例与解释

- [ ] 题面样例 2–4 组，足够小、能手算。
- [ ] 样例输入/输出是纯文本，没有 Markdown 包裹、没有多余空行。
- [ ] 每组样例都有解释，且解释了"为什么是这个输出"。
- [ ] 解释里的公式同样遵守 C 节规则。
- [ ] 表格、列表能正常显示；没有把表格塞成一行文字。

## E. 公式被污染的自检（历史 bug）

- [ ] 保存后**重新打开题面**看一眼公式。
- [ ] 没有出现 `1≤n≤1051 \\le n \\le 10^51≤n≤105` 这种"字形 + TeX 源"重复文本。
- [ ] 没有把 KaTeX 渲染后的 HTML 复制进题面（别从预览/题目页面复制公式）。
- [ ] 没有在"预览"模式里改公式；公式一律在"原文"模式里写。
- [ ] 显示公式 `$$...$$` 没有被降级成 `$...$`。
- [ ] `\\frac`、`\\times`、`\\sim`、`\\le`、`\\operatorname` 都能正常渲染。

## F. 图片

- [ ] 图片独立成段，`![说明](/public/upload/xxx.webp){width=60%}`。
- [ ] 宽度用百分比或像素，未超过容器；小屏不会溢出。
- [ ] alt 写内容说明，不是文件名/哈希。
- [ ] 图片没有替代文字能表达的关键信息。

## G. 数据（10+10）

- [ ] 10 组手造小数据 + 10 组随机/构造大数据，共 20 组。
- [ ] 最小规模、最大规模、全相同、全不同、无解/多解、特殊结构都覆盖。
- [ ] 大数据里有最坏情况（卡时限/内存/深度/总和上限）。
- [ ] OI 写清测试点分值与子任务依赖；ACM 给整包。
- [ ] SPJ 题附 checker 与判定说明；浮点题写误差。
- [ ] 标程跑全包通过，答案文件非空，每组都在时限/内存内。

## H. 命名与文件

- [ ] 变量全文一致，下标从 1 开始，没有 `o/0`、`l/1` 混淆。
- [ ] 测试点 `1.in`/`1.out` … 命名与 ZIP 导入约定一致。
- [ ] 题目标题简洁，没有难度/来源前缀。
- [ ] 题面符号与标程/生成器变量同名。
- [ ] 没有把 `.env`、token、判题机地址、内部路径写进题面。

## I. 历史坏写法速查（出现即打回）

- `a$_1$`、`a1`、`裸 n`、`1≤n≤1e6`
- `1/n`、`n/2`（应为 `\\frac{n}{2}`）
- 独立的 `<h5>数据范围</h5>` 小节或 `data_range` 字段
- 范围堆在输入最后一段、与变量不对应
- 样例说明写在 `hint`
- `($...$)` 括号在数学环境内、缺少 `$`
- 从渲染页面复制出来的公式
